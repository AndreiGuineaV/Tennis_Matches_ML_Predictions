# Tennis Match ML Predictions

A Python project and interactive web dashboard for estimating the winner of men's ATP tennis matches. It builds chronological player-form features, trains and calibrates a gradient-boosted classifier, evaluates predictions on a later period, optionally backtests them against historical betting odds, and makes predictions for upcoming matches.

Predictions and backtests are experimental estimates, not guarantees of match outcomes or profit. Do not treat them as betting advice.

## Project contents

| Path | Purpose |
| --- | --- |
| `tennis.py` | Top-level CLI runner orchestrating feature engineering, training, evaluation, backtesting, and live prediction. |
| `tennis_ml/` | Modular Python package containing `elo.py`, `betting.py`, `features.py`, `model.py`, and `backtest.py`. |
| `tests/` | `unittest`-compatible unit tests for Elo ratings, vig removal, Kelly criterion, and feature generation. |
| `requirements.txt` | Python dependencies (`pandas`, `numpy`, `xgboost`, `scikit-learn`, `openpyxl`). |
| `merged_matches.csv` | Combined historical ATP match results generated by `matches_data_merge.py` and consumed by `tennis.py`. |
| `atp_matches/` | Annual ATP match-result CSVs (`atp_matches_YYYY.csv`). |
| `matches_data_merge.py` | Combines matching annual CSVs from `./atp_matches/` into `./merged_matches.csv` using portable relative paths. |
| `2026.csv` | Additional 2026 match data used by the seasonal merge helper. |
| `new_matches_data_merge.py` | Adds `2026.csv` to `merged_matches.csv`, removes duplicate tournament/match IDs, and sorts the result. |
| `odds/` | Historical tennis-data.co.uk Excel files used by the backtest. |
| `odds_scraping.py` | Downloads yearly odds files for 2010–2026 into `odds/`. |

## Python setup & CLI workflow

Install dependencies from `requirements.txt`:

```bash
python -m pip install -r requirements.txt
```

Run commands from the repository root so relative paths (`./atp_matches`, `./merged_matches.csv`, `./odds`) resolve automatically:

```bash
python matches_data_merge.py
python new_matches_data_merge.py
python tennis.py
```

`matches_data_merge.py` also accepts optional `--input-dir` and `--output` CLI flags if you store match CSVs elsewhere.

### Run unit tests

```bash
python -m unittest discover -s tests -v
```

## Web interface (Node.js + React)

This repository also includes a Node.js + Express + Vite + React web interface on port 3000 (`npm install && npm run dev`) that replicates the chronological feature pipeline, calibrated gradient-boosted model evaluation, historical odds Kelly backtest, and interactive match predictor directly against the CSV and Excel datasets.

## Understanding results and limitations

- **Accuracy** is the fraction of test outcomes classified correctly at a 50% probability threshold.
- **Log loss** and **Brier score** assess probabilistic predictions; lower is better.
- **Calibration output** compares predicted-probability bins with observed win rates.
- **Backtest ROI, drawdown, and CLV** describe the selected historical sample and the odds available to the join. They are not evidence of future profitability.
